## Project Description
Cafe Bliss is a coffee shop website developed as part of Lab 11 and extended for Lab 12. The website provides visitors with information about the cafe, its menu and its gallery.

## Website Theme
- **Theme:** Cafe / Coffee Shop
- **Colors:** Original Cafe Bliss color scheme
- **Technologies:** HTML, CSS and JavaScript

## Website Pages
1. **Home:** Introduction to Cafe Bliss.
2. **Menu:** Displays the cafe's menu.
3. **Gallery:** Shows cafe-related content and images.

- Three connected website pages.

- Shared website styling.

- Responsive project structure (where implemented).
